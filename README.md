# Web Development Project

Лабораторная работа по веб-разработке, выполненная в рамках университетского курса. Проект состоит из двух основных частей: базовой версии (task_1_work) и версии с использованием Bootstrap (task_2_bootstrap).

## Информация о работе

- **Тип работы:** Лабораторная работа
- **Дисциплина:** Веб-разработка
- **Тема:** Разработка адаптивного веб-приложения для просмотра информации о городах
- **Задачи:**
  1. Реализация базовой версии на чистом HTML/CSS/JS
  2. Создание версии с использованием Bootstrap
  3. Интеграция с внешними API (OpenWeather)

## Структура проекта

### Task 1 - Базовая версия
Реализация с использованием чистого HTML, CSS и JavaScript.

- `catalog.html` - Каталог городов
- `index.html` - Главная страница
- Страницы городов:
  - `element_newyork.html`
  - `element_paris.html`
  - `element_tokyo.html`

#### Функциональность
- Интерактивная карта (maps.js)
- Система избранного (favorites.js)
- Отслеживание прогресса (progress.js)
- Погодный виджет (weather.js)
- Адаптивный дизайн (components.css, style.css)

### Task 2 - Bootstrap версия
Переработанная версия с использованием фреймворка Bootstrap.

## Особенности

- Интеграция с OpenWeather API для отображения актуальной погоды
- Адаптивный дизайн для различных устройств
- Интерактивные элементы и анимации
- Система избранных мест
- Визуализация прогресса просмотра

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap (в task_2_bootstrap)
- OpenWeather API

## Медиа ресурсы

Проект включает изображения городов и иконки:
- Виды городов (new_york.jpg, paris_view.jpg, tokyo_view.jpg)
- Иконки (plane.png, rocket.png)

## Запуск проекта

1. Склонируйте репозиторий
2. Откройте index.html в веб-браузере
3. Для работы погодного виджета необходим API ключ OpenWeather (уже настроен)
